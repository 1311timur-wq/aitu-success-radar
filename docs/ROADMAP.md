# Roadmap

## v1.0 — финальная версия курса ✅
- Регистрация студентов с валидацией и подтверждением почты, вход и сброс пароля; преподавателей создаёт администратор.
- Панель администратора: аналитика, пользователи, курсы, состав курса, коды, резервные копии, CSV, журнал.
- Вступление в курс по коду и QR; «Мой план на неделю»; IoT — QR-отметка у двери с кодом по времени сервера.
- Резервное копирование: панель, `npm run backup`, ночной GitHub Actions; `npm run restore` с пробным прогоном.
- Заголовки безопасности, авто-выход, CI (typecheck, тесты, правила на эмуляторе).

## Шаг 2.5 — правила AITU ✅ (v0.5)
- Журнал оценок с регистрами, весами и допуском; Radar студента «По правилам AITU» с прогнозом GPA и стипендии; рекомендации с числами.
- Выбор аудитории с поиском по каталогу.

## Шаг 2 — My DU на реальных данных ✅ (v0.4)
- `apps/student`: дизайн реплики сохранён. Вход — Firebase Auth (Splash, Dew, код-пароль и Face ID остались визуальными заставками), профиль берётся из `users/{uid}`, Radar работает через `watchStudentRadar`.
- Вместо «72/100» — кольцо по состояниям курсов и «фокус-курс». Вместо «среднего по классу» — порог из политики курса. Динамика строится только по опубликованным оценкам.
- Состояния «Мало данных», «Нет соединения», «Обновлено…», «Исправлено преподавателем». Пустой и ошибочный экраны.
- Service worker кэширует только оболочку приложения. Данные Firestore не кэшируются никогда.

## Шаг 3 — укрепление
- Прогнать `npm run test:rules` в CI (GitHub Actions + Java). Добавить Playwright E2E для двух ролей: студент A не открывает данные студента B, неназначенный преподаватель видит «нет доступа».
- Админ-скрипт зачислений с API, а не только seed: `scripts/admin/enroll.ts` держит `studentUids` и `enrollments` согласованными.
- Firebase App Check и отдельные проекты `dev` / `prod`; budget alerts.

## Firebase: когда нужен Blaze
Spark (бесплатно): Auth, Firestore — 50 тыс. чтений и 20 тыс. записей в день, 1 ГиБ, Hosting. Для ICT-демо этого хватает с запасом.
Blaze понадобится для Cloud Functions (уведомления, серверные сводки, интеграции). В пределах бесплатной квоты Blaze обычно стоит $0, но нужны карта и budget alert.

## Ограничения (честно)
- Правила v1.0 проверены компилятором при деплое и тестами `npm run test:rules` (эмулятор, нужна Java) — их обязательно прогнать после обновления. Офлайн-демо правила не проверяет.
- QR-отметку можно передать другу, если он стоит у двери в те же 45 секунд, — как и любую перекличку. Защита от «отметки из общежития», а не от сговора; итог всё равно подтверждает преподаватель.
- Перебор 6-значного кода за 45 секунд из браузера нереален, но лимита попыток в правилах нет (нужны App Check или Cloud Functions).
- Квота Spark — 50 тыс. чтений в день. Страница курса читает весь журнал группы (≈300–900 документов), главная — только черновики. Для демо этого достаточно. При росте: агрегатные `count()` и постраничная загрузка.
- Публикация из нескольких коммитов в группе больше 8 человек может на долю секунды показать студенту часть отметок. Флаг `attendancePublication = published` ставится последним.
- Teacher Portal оформлен по мотивам Moodle 4: настоящий преподавательский интерфейс LMS AITU неизвестен.
