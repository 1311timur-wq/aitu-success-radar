# Безопасность — AITU Student Success Radar v1.0

Своего сервера нет: Firebase (Auth + Firestore + Hosting) — это BaaS, а «серверная» проверка каждого запроса — `firestore/firestore.rules`. Клиенту не доверяем: всё, что проверяет форма, правила проверяют ещё раз.

## Модель угроз (кратко)

| Кто | Что может попытаться | Что мешает |
|---|---|---|
| Студент | Прочитать чужие оценки, поставить себе оценку, стать преподавателем | Rules: чтение только своих **опубликованных** записей; запись журнала — только staff курса; роль при регистрации принудительно `student` |
| Студент | Вступить в чужой курс, добавить друга | Нужен активный код именно этого курса; добавить можно только себя; почта подтверждена |
| Студент | Отметиться «из дома» по фото QR | Код живёт 45 с по времени **сервера**, студенты не читают текущий код из базы, одна отметка на занятие, итог подтверждает преподаватель |
| Посторонний | Зарегистрироваться на чужую корпоративную почту | Регистрация возможна, но вступление в курс требует `email_verified` — ссылку получит только владелец ящика |
| Посторонний | Перебрать коды курсов | `list` для `joinCodes` закрыт, только `get` по точному коду; 31⁶ ≈ 887 млн вариантов |
| Преподаватель | Править чужой курс, назначить себя администратором | Rules: `uid in staffUids`; admin — только claim в токене (Admin SDK) |
| Администратор (ошибка) | Удалить данные | `delete` запрещён для курсов, пользователей, журналов; архив вместо удаления; копии и восстановление с пробным прогоном |
| Сторонний сайт | Встроить портал во фрейм (clickjacking), подгрузить скрипт | `X-Frame-Options: DENY`, `frame-ancestors 'none'`, CSP `script-src 'self'` |

## Аутентификация
- Пароли хранит и хэширует **Firebase Auth**; в нашей базе паролей нет.
- Пароль студента: ≥ 8 символов, буквы и цифры, не содержит имя из почты, индикатор надёжности (`checkPassword`).
- Преподаватель получает **временный** пароль (12 символов, криптостойкий генератор, показывается один раз) и обязан сменить его при первом входе (`mustChangePassword`, правила разрешают снять флаг только вместе с `passwordChangedAt == request.time`).
- «Забыли пароль?» не сообщает, существует ли аккаунт (защита от перебора почт).
- Смена пароля требует текущий пароль (повторная аутентификация).
- Портал преподавателя выходит из аккаунта после **30 минут** бездействия (общие компьютеры в аудиториях).

## Авторизация (Security Rules)
| Ресурс | Правило |
|---|---|
| `users/{uid}` | Читает сам и администратор; студент создаёт только себя (`role: 'student'`, почта = почта токена, корпоративный домен, проверка всех полей); роль и почту изменить нельзя |
| Роль администратора | `request.auth.token.admin == true` — ставит только `npm run make-admin` (Admin SDK) |
| Журнал курса | Пишет только staff курса; `revision + 1`, автор и время сервера, баллы в диапазоне; изменение опубликованного — только с причиной (`audit`) |
| Студент | Читает только свои записи и только `published` |
| `joinCodes` | `get` по коду; `list` — администратор; превью совпадает с курсом |
| Вступление | Одна пачка: себя в `studentUids` + зачисление с кодом; курс активен; код активен; почта подтверждена (демо-аккаунты — только в демо-курсы) |
| `checkinTokens` | Читает и пишет только staff курса |
| `checkins` | Создаёт сам зачисленный студент, один раз, со свежим кодом; изменить и удалить нельзя |
| `audit`, `adminLog` | Только добавление |
| `stats/latest` | Только администратор |

Проверка: `npm run test:rules` (52 + 3 теста на эмуляторе), `npm run check:student` на живой базе.

## Заголовки HTTP (`firebase.json`)
| Заголовок | Значение и смысл |
|---|---|
| `Content-Security-Policy` | скрипты только с нашего домена; подключения только к Firebase; `object-src 'none'`, `base-uri 'self'`, `form-action 'self'`, `frame-ancestors 'none'`, `upgrade-insecure-requests` |
| `Strict-Transport-Security` | только HTTPS, 1 год, с поддоменами |
| `X-Frame-Options: DENY` | нельзя встроить во фрейм |
| `X-Content-Type-Options: nosniff` | браузер не «угадывает» тип файла |
| `Referrer-Policy: strict-origin-when-cross-origin` | адреса страниц не утекают на другие сайты |
| `Permissions-Policy` | камера, микрофон, геолокация, платежи выключены (QR сканирует системная камера телефона) |
| `Cross-Origin-Opener-Policy: same-origin-allow-popups` | изоляция окна |

Проверить: DevTools → Network → любой ответ `…web.app` → Response Headers, или https://securityheaders.com.

## Секреты
- Ключ сервисного аккаунта (для `seed`, `backup`, `restore`, `make-admin`, `iot:simulate`) хранится **вне папки проекта**, путь — в `.env`. `.env`, `service-account*.json`, `backups/` — в `.gitignore` и не попадают в zip.
- Web-конфиг (`apiKey` и т. п.) — **не секрет**: он есть в любом Firebase-сайте, доступ защищают Rules.
- Для ночной копии ключ лежит в GitHub Secrets; репозиторий должен быть **приватным**.

## Данные и приватность
- В базе только синтетические данные; демо-пароль `demo-pass-2026` публичный.
- Экран у двери показывает только количество отметившихся.
- CSV-выгрузка использует псевдонимы `S001…`, а не имена.
- Резервная копия содержит персональные данные (ФИО, почты) → хранить как конфиденциальный файл, не публиковать.
- Восстановление из браузера отсутствует намеренно.
